**结论：PASS（SIM_ONLY，选定的离散参考轨迹）。** 从 B1-S0 已筛查的 q=0 出发，完成关节空间进入、固定姿态圆周加速、恒定角速度一圈、减速、返回及保持的全序列。没有将厂商示例角度当成安全输入。全部参数仅用于此仿真。

## 圆与参考点

参考点为未经工具偏置的 `link6` frame，位置均相对 `base_link`。恒速段用 `x=xc+r*cos(ωt)`、`y=yc+r*sin(ωt)`、`z=zc`，t从恒速段开始计时。

| 参数 | 选定 SIM_ONLY 数值 |
|---|---|
| 圆心 m | `(0.3300382964089144, 0.007054066113572588, 0.4020848551710966)` |
| 半径 | `0.010 m` |
| 一圈周期 / 角速度 | `8.0 s / 0.7853981634 rad/s` |
| 恒速末端线速度 | `0.0078539816 m/s` |
| 初始/最终 q rad | `[0,0,0,0,0,0]` |
| 进入后 q_home rad | `[0,0.2,-0.2,0.2,0.3,0.2]` |

固定姿态取 q_home 的 URDF FK 旋转矩阵，保存在 [规划数值](data/B1_S1_TRAJECTORY_SUMMARY.json)的 `home_pose_link6`，整个圆周加速/恒速/减速段都保持同一姿态目标。进入和返回采用关节空间插值，其末端姿态会随 q 平滑变化，不承担笛卡尔固定姿态约束。`link6` 仍不是实机标定 TCP。

q_home 位于圆的相位 `-π/8`；1秒加速后到相位0，恒速段走0→2π，再用1秒减速到 `2π+π/8`。圆心由 q_home 的 FK 和该起始相位反算，最终返回从减速末状态开始，避免错误地跳回 q_home。

## IK、搜索与时间序列

[IK函数](../../src/robot_rl_sim2real/circle_trajectory.py#L71)使用有界非线性最小二乘 `scipy.optimize.least_squares`（TRF，数值雅可比，前一点解热启动）。残差为位置除以0.01 m后的三维差，加三维旋转向量；每点要求成功且残差≤`1e-7`，位置界来自原厂 URDF。没有从 axis 符号或 SDK 名称猜测实机方向。

离线比较半径 `{5,10} mm`、周期 `{6,8,10} s` 的6个候选，每候选61个几何点；最终选择10 mm/8 s，并以240 Hz重新求解和筛查完整时序。[配置](../../configs/b1_s1_circle_sim_only.json)和[生成脚本](../../scripts/generate_circle_trajectory.py#L102)记录输入来源。此搜索不声称全局最优或最大工作空间。

| 阶段 | 仿真时段 s | 参考样本数 |
|---|---:|---:|
| 初始保持 | 0–2 | 480 |
| q=0→q_home | 2–4 | 480 |
| 圆周速度渐增 | 4–5 | 239 |
| 恒速完整一圈 | 5–13 | 1,921（含5秒边界点） |
| 圆周速度渐减 | 13–14 | 240 |
| 返回 q=0 | 14–16 | 480 |
| 最终保持 | 16–18 | 480 |

进入/返回使用五次多项式平滑阶跃，端点速度和加速度为0。圆周速度用同一五次阶跃加减速，其积分给相位；恒速一圈仍严格使用 ωt。初版直接进入恒速圆造成约10.9 rad/s²参考加速度尖峰，完整过渡筛查将其拒绝；未把该版本作为正式执行输入。

## 全路径筛查

- 共4,320个参考配置，最大相邻关节步幅 `0.0011718614 rad`，最大参考速度 `0.2812467 rad/s`，最大参考加速度 `0.4329836 rad/s²`；低于本试验的0.5 rad/s、2 rad/s²门限。全序列位置界最小余量约 `0.523599 rad`，无2π跳支。
- 圆周 IK 最大缩放残差约 `1.24e-14`；位置和姿态重建残差分别约 `1.24e-16 m`、`3.03e-15 rad`。这是同模型数值求解精度，不是硬件精度。
- 每8个参考点及每阶段末点检查6×6雅可比 SVD。恒速圆最小奇异值 `0.0494942`、最大条件数约 `35.666`，通过本次σ≥0.01门限。该指标混合 m/rad 单位，仅作同定义下的局部诊断。
- **q=0 是接近腕部奇异的配置**：σ约`1.37e-7`、条件数约`1.29e7`。进入/返回采用关节空间插值，无需在该点反解笛卡尔速度；圆周 IK 不在此奇异区域执行。不能把这段关节插值验证推广为奇异位形附近的任意笛卡尔控制。
- 每个参考点先做 CAD 凸包非邻接筛查；正式运动前再以运行时 cooked/CAD 联合外包络及每体1 mm接触余量筛查全序列。进入、停止和返回均包含在内，详见 [碰撞报告](B1_S1_COLLISION_VALIDATION.md)。

规划实际输出在 `runs/b1_s1/plan_005/{trajectory.jsonl,trajectory_config.json,summary.json}`，文件hash与执行端绑定，未通过或hash不符的参考不能执行。公开的是[脱敏规划摘要](data/B1_S1_TRAJECTORY_SUMMARY.json)。厂商原始 URDF、mesh、USD 只从本地读取。
