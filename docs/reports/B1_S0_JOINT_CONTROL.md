# B1-S0：最小关节位置控制

日期：2026-11-13（KST）。**结论：PASS（SIM_ONLY，小幅局部试验）**。两次独立运行都完成静止保持与六轴正负单关节小步，数值和映射一致。这不证明实物能接受位置流，也不证明真实运动安全或达到同样精度。

## 控制方式与实验

[配置](../../configs/b1_s0_sim_only.json) 选择 Isaac Lab 显式 `IdealPDActuator`，六轴相同的 `Kp=200 Nm/rad`、`Kd=4 Nm·s/rad`、armature `0.02 kg·m²`、摩擦 `0`、effort clip `±20 Nm` 和 PhysX velocity limit `0.5 rad/s` 均为 **SIM_ONLY**，没有厂商标定来源。按数值基线取 `Kd=2√(Kp×armature)=4`，步长满足 `dt√(Kp/armature)=0.4167`；这只是本试验的选值理由，不是稳定性证明或硬件整定建议。CAD 刚体惯量与附加 armature 分开记录。

每轮先保持 `q_target=[0,0,0,0,0,0] rad` 两秒；之后对每个关节依次设 `+0.01 rad → 0 → -0.01 rad → 0`，每阶段一秒，其余五轴目标维持零。共25个阶段、26 s、6,240个 1/240 s 采样。脚本在每次物理步将位置和零速度目标送入显式 PD，读取下一步真实仿真 q、dq 和 link6 pose，记录未裁剪及裁剪后的命令、PhysX 关节投影力矩、误差和时间戳（[代码](../../scripts/validate_sim_robot.py#L291)）。命令时间是 `t-dt`，状态时间是 `t`。

`joint_effort_nm` 是 PD 裁剪后发往 PhysX 的**仿真命令力矩**；`computed_torque_nm` 为裁剪前命令；`projected_joint_force_nm` 为 PhysX incoming joint wrench 沿 DoF 的投影，包含约束和其他动力学作用，不能称为电机扭矩传感器。没有读取真实力矩。显式 PD 会使 USD 隐式 drive stiffness/damping 为0，以免重复驱动；这并非关闭 PD。

停止条件和诊断门限也是 SIM_ONLY：每步检查名字、有限性、URDF 位置界、`|dq|≤0.55 rad/s`、命令 effort、FK 误差和碰撞；每阶段检查末0.25 s 最大跟踪误差≤0.03 rad、速度≤0.02 rad/s、接近 effort 上限的样本比例≤5%，目标变化轴实际位移同向且至少达到目标步幅的20%。0.03 rad 大于本试验单步幅，因此不能单独证明跟踪，实际响应幅值另列如下；这些阈值不是精度或安全规格。方法见 [数据验证](../../src/robot_rl_sim2real/sim_validation.py#L40) 和[阶段判断](../../scripts/validate_sim_robot.py#L339)。

## 实测结果

两轮各25个阶段均完成，无停止原因；同一时间点 q、dq、目标和命令 effort 的最大差为0。静止保持末0.25 s 六轴最大 `|q_target-q_actual|=0.00450161 rad`，最大 `|dq|=3.49e-7 rad/s`；末状态 q2≈0.00450161、q3≈0.00443977 rad，说明有重力下的静差，并非完美零误差。整个实验最大 `|dq|=0.416567 rad/s`，最大裁剪后 `|effort|=2.93354 Nm`；所有阶段达到99% effort 上限的样本比例为0%。末0.25 s 跨全部阶段最大 `|error|=0.00466769 rad`、最大 `|dq|=7.25e-7 rad/s`。
