# B2-S0：圆轨迹 RL 环境设计

日期：2026-11-13（KST）；输入基线：`1704d1b8b3b68f20128061962c96212e466f929c`。**范围为 SIM_ONLY。** 本阶段实现并测试环境，不注册 PPO 训练任务，不运行训练或访问真实机器人。

## 任务与执行结构

[CircleTrackingEnv](../../src/robot_rl_sim2real/isaac_circle_env.py#L56) 继承 Isaac Lab `DirectRLEnv`，使用 B1-S1 相同私有 USD、普通 PD 或显式选择的模型重力前馈。环境有一台固定基座机械臂，无夹爪、相机、桌面或任务物体；link6 原点为临时参考点，全部位置相对 base_link。当前实现仅允许 **1–4 个 CPU 环境**，使用逐环境 CPU URDF FK、雅可比和 CAD+cooked 凸包检查，优先可审计，不代表大量并行训练的吞吐量。

B1-S1 圆心 `(0.3300382964, 0.0070540661, 0.4020848552) m`、半径 `0.010 m`、恒速周期 `8 s` 不变。每个 episode 从 q_home 附近开始：`0–1 s` 五次平滑加速，`1–9 s` 恒速一圈，`9–10 s` 平滑减速，`10–10.5 s` 保持；最大 630 个控制步。初始相位固定为 `-π/8`，不在本阶段随机化圆相位或扩大工作空间。物理 `dt=1/240 s`，每四个物理步接受一个 60 Hz 动作。参考速度随模拟 episode 时间更新；进入本地圆起点由已检查 reset 完成，而非让策略学习 q=0 的整段进入运动。参考公式见[实现](../../src/robot_rl_sim2real/circle_rl.py#L11)和 [B1-S1轨迹报告](B1_S1_CIRCLE_TRAJECTORY.md)。

本任务设为 `is_finite_horizon=True`：完成一次减速/保持后是有限任务结束。Isaac 的 `DirectRLEnv` 仍用 `truncated` 返回时间到期；将来接入训练封装时必须遵循这一配置，不能把已经完成的轨迹当作无限任务错误 bootstrap。当前没有创建或测试训练封装。

固定姿态为 q_home 的 FK 朝向；本版以 **0.05 rad 姿态偏离终止门**约束实际运动，并非严格零姿态误差或姿态奖励。末端位置误差用于跟踪奖励。两种控制器的 Kp=200 Nm/rad、Kd=4 Nm·s/rad、armature=0.02 kg·m²、摩擦0、力矩裁剪±20 Nm、物理速度上限0.5 rad/s 均与 B1-S1 的 SIM_ONLY 配置一致。`pd` 是默认；`pd_gravity` 在同一 PD 上添加仿真模型重力前馈并经过同一力矩裁剪。配置与运行记录均含控制器模式，二者的结果不能混作同一控制器。模型重力前馈不是 SDK 已确认能力。

## Reset、隔离与安全边界

每个环境独立伪随机数流；reset 从 `[0,0.2,-0.2,0.2,0.3,0.2] rad` 每轴均匀扰动 ±0.001 rad，速度、动作历史、目标和 episode 时钟复位。每次候选都检查原厂模型位置界及本地关节界、固定姿态偏差、位置偏差、雅可比最小奇异值、CAD+cooked 联合凸包和每形体 1 mm 接触余量；最多尝试32次，不合格则报错而不是使用未经检查的后备姿态。随后物理步继续检查接触和状态。参考点和姿态阈值都是 SIM_ONLY，不是实机安全姿态。

场景使用 CPU 环境间碰撞隔离；每个机械臂内部 self-collision 和 collider 保留。按 B1-S1 设置全局接触处理，核对每个副本 cooked hull 与第一个副本相同（浮点容差 `1e-10`），再采用联合凸包筛查。两类碰撞证据是物理接触回调与非邻接几何判定；也分别检查模型限位、局部关节界、非有限值、速度/加速度、位置与姿态偏差、局部奇异性和 FK 名称映射。[终止条件](../../src/robot_rl_sim2real/isaac_circle_env.py#L253)不依赖奖励数值。碰撞回调跨 240 Hz 子步累计，几何和终止在 60 Hz 控制步检查：一次控制步最多经过四个物理子步才返回终止，**不是实时急停或连续扫掠验证**。

观测和动作定义见 [接口报告](B2_S0_OBSERVATION_ACTION.md)，奖励、实验和故障注入见 [测试报告](B2_S0_REWARD_RESET_TESTS.md)。原始日志、输入配置、完整状态轨迹、各分量和派生 cooked 顶点仅保存在 git 忽略的本地 `runs/b2_s0/`；公开材料仅含脱敏摘要。历史 [B1-S1 普通 PD 基线](B1_S1_CLASSICAL_BASELINE.md)和独立重力对照保留。

## 边界与下一步

实机 SDK 的目标覆盖、连续下发速率、状态时间戳、速度反馈和停止语义仍 UNKNOWN；模型质量、执行器参数、角度映射、TCP、安装与真实障碍物也未标定。此环境不具备实机动作契约。环境首版使用 5 mm 误差尺度的截断跟踪项，误差超过尺度后跟踪项趋于常数，学习信号可能稀疏；需要在 B2-S1 单独检查，不将当前非训练测试称为策略有效性。
