# 项目章程｜最小 Sim2Real

## 为什么做
研究者已有 PegInsert PPO、ManiSkill PickCube PPO 和 FR3 仿真经验；当前欠缺“真实机器人型号→训练→真实策略执行”的完整可核验证据。本项目专门补齐该闭环。

## 成功定义
同一个可追溯的 PPO Actor 权重，在仿真训练并独立评估后，经独立安全过滤器接入真实机器人，**低速、无接触**地闭环跟踪一条空中圆形参考轨迹，记录真实的状态、参考、策略动作、安全过滤结果、指令和响应时间戳；完成仿真/实机对比。未完成真机策略执行则为 PARTIAL。

## 任务冻结范围
- 最初只做 3D 位置的固定平面小圆形轨迹跟踪，机器人末端不接触物体；不用相机、夹爪、吸盘。
- 圆心、半径、周期和初态暂不填写具体数值：必须由 B0 安全可达空间审查确定。
- 第一版的姿态目标可以固定，但必须明确末端工具坐标系；不固定前不训练。
- PPO 通过低层已验证的位置接口输出受限的关节参考值；**不直接输出电机力矩**。
- 默认用 FK 从实测关节位置估计 TCP 实际轨迹；相机不是必需项。
- 为了避免策略只是记忆一段开环指令，Actor 至少获得实时观测与参考误差；实机验收需要检验反馈中断后的停机行为与真实动作闭环。

## 非目标
算法创新、PPO vs Residual RL 选型、接触操作、抓取、避障、双臂、视觉/深度学习感知、世界模型、复杂运动模仿、多算法横向比较。未经另行决定不要扩张范围。

## 核心成功证据
1. 机器人与控制器契约获验证（不是仅仅 URDF 能加载）。
2. 确实训练出的 PPO checkpoint + config + 随机种子。
3. Actor 真实可用的 Observation；动作到电机控制的映射一致。
4. 仿真独立评估与真实机器人执行日志；不能用仿真成绩代替实机。
5. 与传统跟踪基线比较；如果 RL 不如传统控制也如实报告。
6. 学习验收单独进行，Codex 的 PASS 不代表研究者理解。
