# B0–B7 实施路线（每阶段需审阅，不自动跨门）

| 阶段 | 内容 | 可交付证据 | 放行前提 |
|---|---|---|---|
| B0 | 型号、URDF/mesh、关节顺序/零位、限制、驱动模式、厂商 SDK 能力与 ROS 时序审查 | `docs/reports/B0_*.md`，模型审计数据、仍未知的硬件参数 | 明确安全工作空间与实机是否支持更新位置目标；不能猜参数 |
| B1 | Isaac Lab 2.1.1 候选环境导入、简单控制与 FK 校验 | 导入脚本、joint mapping、静态姿态/FK 和无策略 motion smoke | 已有版本/资源审查，不盲升软件 |
| B2 | 单一圆形轨迹 MDP、reset、reference、observation、action、reward、安全边界；传统基线 | 零动作/随机动作、碰撞、done、基本 PD/IK 轨迹验证 | MDP 每个量有物理定义；安全不靠 reward |
| B3 | PPO 小型 smoke→正式训练，先固定半径和速度，确定性评估 | config、seed、模型权重、训练曲线、异常检验 | 正式训练需 GPU/时长授权 |
| B4 | 留出初态/可达圆心评估与失败回放 | RMSE、P95、最大轨迹误差、平滑性、延迟估算、失败轨迹 | 不以单次精美视频当成功证明 |
| B5 | Actor 独立推理、状态映射、时序和安全层，离线 replay + shadow 推理 | I/O 契约、超时/丢包/越界/关节限位故障注入 | 现场实机允许之前，绝不下发硬件动作 |
| B6 | 现场有限低速实机闭环 | 真机独立状态日志、实际控制周期、摄像/视频备份（需授权） | 人在现场、急停就绪、厂商限制保留、已批准窗口 |
| B7 | Real-vs-Sim、传统基线对比与收尾 | 可复现命令、图表、失败、真实视频、面试摘要 | 不得隐瞒未验证部分 |

### 变更管理
B0 未完成时，不允许锁定频率、关节增量、圆半径、初始姿态、精度阈值；B1 之前不开始 PPO；B5 之前不进行策略实机执行。
