# 最小实验协议（未冻结的数值均待实测）

## 实验阶段
- P0：圆形参考生成器数学与单位测试（纯 CPU，无机器人）。
- P1：Isaac Lab 仿真中无策略控制、零动作和随机动作；检查关节/碰撞/时序。
- P2：PPO 小型 smoke，证明优化流程可运行，不把 reward 提升误判为成功。
- P3：固定任务训练，至少独立评价不与训练重用初态/相位；如训练多个种子，分开统计。
- P4：导出 Actor，独立于训练脚本在同一 Isaac 环境中运行。
- P5：真实设备 shadow inference，验证状态映射与指令的有界性。
- P6：现场授权下真实设备闭环跟踪一个小圆，记录真实状态。
- P7：同路径同速度下 PPO 与 IK/轨迹控制传统基线，以及仿真 vs 实机比较。
- P8：只有发现必要的 gap 并有实测范围后，再考虑 Domain Randomization；不是初期必选。

## 重要指标
- 轨迹跟踪误差：同步参考位置与 FK TCP 的空间距离；报告 RMSE、均值、P95、最大值（米/毫米明确）。
- 时序：推理 P50/P95、状态年龄、指令发送周期、指令到状态的响应延迟、丢帧/超时。
- 控制质量：关节速度/加速度峰值、目标增量饱和率、安全过滤拒绝数、意外停机事件。
- 工作空间：最小桌面/环境距离、关节限位余量、发生碰撞次数（目标为 0）。
- 成功：完整走完预定圈数、没有安全门触发、误差处于**事先冻结的容差范围**；不能在结果出来后修改成功阈值。

## 证据要求
每条试验都有运行 ID、Git SHA、model checksum、训练/测试 seed、版本、配置、初态、参考轨迹、原始状态和命令日志、最终 metrics。日志能区分参考、请求、限幅后实际指令、测得状态。实机报告明确授权、环境与失败处理。
