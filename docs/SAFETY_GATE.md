# 实机运行硬门禁

## 未获以下证据，禁止向硬件下发 PPO 动作

1. 型号、真实安装、法兰/TCP、6 轴角度映射、关节方向/零位、软硬限位均完成实机/厂商核验。
2. 机器人状态读取具有可靠时间戳，并能识别数据过期、丢失和通信中断。
3. 位置指令覆盖/排队与有效控制周期经过 SDK 文档或受控测试确认，未确认前只读。
4. 安全工作空间、桌面/底座/自碰撞检查和运动边界经现场人员审批。
5. 独立于 RL 奖励的限幅器、异常停止和实体急停可用；不能关闭厂商保护。
6. shadow actor（只推理不下发）与故障注入（过期观测、NaN、超界动作、失联）通过。
7. 先以厂商批准的极小范围、低速、人工在场进行执行；策略未知动作直接拒绝。
8. 必须有一个独立测试方法验证实际关节角/末端位置；Action 返回“成功”不充分。

**安全责任边界**：本仓库只提供工程程序和审查门禁。现场机器人使能、机械/电气安全判断、急停可用性由具备权限的现场人员负责。Codex/ChatGPT 不得自行启动实机运行。
